Privacy Policy

Bamtolking Upload Tool. Last updated: November 5, 2026.

Who uses this tool

This is a private desktop tool used only by the owner of the connected YouTube channels. It is not offered to the public.

What it accesses

With the owner's permission, it uses YouTube API Services to manage videos, thumbnails, captions and comments on the owner's channels, and to read those channels' analytics.

What is stored

Authorization tokens and channel records stay on the owner's own computer. The tool has no server, and it does not sell or share this data. Comments that viewers post publicly on YouTube may be read so the owner can reply to them.

How to remove access

Access can be removed at any time on the Google Account permissions page.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions can be posted as an issue on this site's GitHub repository.
